# Conception Orientée Objet

Ce repository contient quelques exemples et exerices liés aux éléments abordés pendant le cours. Chaque exercice a une branche de départ avec la donnée et le code de départ ainsi qu'une branche contenant le code terminé.

# Exercices

## Shapes
Exercice de rappel sur les interfaces et leur utilisation.
- Branche de départ `shapes-exercice`
- Branche corrigé `shapes-exercice-correction`

## Singleton Pattern
Exercice court sur l'implémentation du singleton pattern
- Branche de départ `singleton-pattern-exercice`
- Branche corrigé `singleton-pattern-exercice-correction`

## Template Method Pattern
Exercice de refactoring pour utiliser l'héritage et le polymorphisme et finalement le **Template Method Pattern**
- Branche de départ `template-method-exercice`
- Branche corrigé partiel (point 1 et 2) `template-method-exerice-halfway`
- Branche corrigé complet `template-method-exercice-correction`

## Dependency Injection
Le point de départ de cet exercice est la fin de l'exercice sur le template method pattern. Il illustre l'utilisation de l'injection de dépendance par constructeur.
- Branche de départ `dep-inject-exercice`
- Branche de corrigé partiel `dep-inject-exercice-corr-part-I`
- Branche de corrigé complet `dep-inject-exercice-corr-part-II`
